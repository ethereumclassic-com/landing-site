# ETC network mark

`etc-diamond.png` — the official full-color faceted Ethereum Classic diamond.

**This signals the NETWORK, not this website.** Use it wherever the subject is the
chain or the asset itself: chain selectors, token rows, network badges — the same
role it plays in a wallet or a dApp.

## What to use instead, for the website

| Need | Use |
|---|---|
| The site's mark, in a page | `app/components/ui/EtcMark.tsx` — paints in `currentColor`, so it follows the theme |
| The site's mark, as a URL | `public/brand/etc-diamond-flat.svg` |
| Favicon / touch / PWA icons | `public/icons/`, generated by `pnpm brand:icons` |

All three come from `brand/logo/etc-mark.svg`, which is the source of truth.

## Why the split is enforced rather than a preference

- **Meaning.** If the network mark doubles as the site logo, it stops signaling
  the network and just means "this page."
- **Legibility.** The faceted diamond's light and dark greens turn to mud below
  about 32px, which is most of where an icon is actually seen.

Nothing regenerates this file — it is an upstream asset, not a derived one.
