# ethereumclassic.com

The home of Ethereum Classic: wallets, exchanges, apps, mining, development and research, with network figures read from the chain and each specification linked to its source.

Ethereum Classic is immutable infrastructure for programmable global finance: the only mature Proof-of-Work blockchain with native smart contracts, permissionless, censorship-resistant, and operating continuously since 2015.

**Visit [ethereumclassic.com](https://ethereumclassic.com)**

## On the Site

- **[News](https://ethereumclassic.com/news)**: network updates, security notices, and ecosystem, community and development news
- **[Wallets](https://ethereumclassic.com/wallet)**: wallet reviews, comparisons and setup, hardware wallets and MetaMask included
- **[Apps](https://ethereumclassic.com/apps)**: DeFi, payments, governance, tools and infrastructure on Ethereum Classic
- **[Buy and Sell](https://ethereumclassic.com/buy)**: exchanges, card and bank purchases, peer-to-peer trading and crypto ATMs
- **[Learn](https://ethereumclassic.com/learn)**: guides to the basics, wallets, trading, DeFi, mining and security
- **[Markets](https://ethereumclassic.com/markets)**: the ETC price, charts and market data
- **[Research](https://ethereumclassic.com/research)**: the emission schedule, supply, network data and historical data
- **[Mining](https://ethereumclassic.com/mining)**: pools, hardware, software, profitability and network statistics
- **[Build](https://ethereumclassic.com/build)**: node clients, developer tools, networks, testnet faucets and grants
- **[Tools](https://ethereumclassic.com/tools)**: a price converter, an investment calculator, a gas tracker and block explorers
- **[Olympia](https://ethereumclassic.com/olympia)**: a proposed upgrade that would bring EVM alignment through Fusaka and into Glamsterdam, credit an EIP-1559 base fee to a treasury instead of destroying it as Ethereum does, and make Olympia DAO the only way that treasury could be spent

## Where the Figures Come From

- **Chain figures**: block height, block time, difficulty, hashrate, pool shares and fees, read from [Blockscout](https://etc.blockscout.com), the open-source explorer
- **Prices**: [CoinGecko](https://www.coingecko.com/en/coins/ethereum-classic), with Blockscout's copy of the same price when CoinGecko cannot be reached, and Kraken's weekly closing price for history older than a year
- **Specifications**: the [ECIPs](https://github.com/ethereumclassic/ECIPs), Ethereum Classic's improvement proposals, linked from each page that describes one
- **Clients**: each client's own project, [coregeth.com](https://coregeth.com) for Core-Geth and [fukuii.com](https://fukuii.com) for Fukuii

A figure no source supplies shows as a dash, never as an old number.
